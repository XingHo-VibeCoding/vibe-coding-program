## 项目：每日一个 AI 概念详解

一个每天介绍一个 AI 概念的网站。

### 项目简介

- 目标：用简单易懂的方式，每天讲解 1 个 AI 核心概念
- 形式：网站
- 当前进度：**Day 2**（仓库初始化 + 首页占位页），MVP 计划在 Day 7 开始

### 本地运行

直接双击 `index.html` 即可打开当前占位页。

> 待补充：后续接入构建工具后，请在此写明安装与启动命令，例如
>
> ```bash

> ```

### 环境变量

本项目使用 `.env` 保存敏感配置（API Key、数据库密码等）。

1. 复制示例文件：`cp .env.example .env`
2. 在 `.env` 中填入真实值
3. `.env` 已被 `.gitignore` 忽略，**不会被上传到 GitHub**

### 目录结构

```
.
├── index.html        # 网站首页（Day 2 占位页）
├── .gitignore        # 忽略规则：密钥、依赖、本地数据库等
├── .env.example      # 环境变量模板（仅含变量名）
└── README.md
```
