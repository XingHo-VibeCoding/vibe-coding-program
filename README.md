## 项目：每日一个 AI 概念详解

一个每天介绍一个 AI 概念的网站。

### 项目简介

- 目标：用简单易懂的方式，每天讲解 1 个 AI 核心概念
- 形式：网站
- 当前进度：**Day 2**（仓库初始化 + 首页占位页），MVP 计划在 Day 7 开始

### 本地运行

**不需要安装任何东西，也没有构建步骤。** 直接双击 `index.html` 即可在浏览器打开。

用命令行打开（可选）：

```bash
start index.html     # Windows
open  index.html     # macOS
```

页面需要 JavaScript 才能显示内容：概念数据存在 `concepts.js` 里，由浏览器读取后渲染。

> 详情页 `concept.html` 需要地址里带概念编号（形如 `concept.html?id=007-rag`）才会显示内容。
> 不带编号直接打开，会看到一个「没有指定要看哪个概念」的提示页。正常入口是从首页点卡片进去。

首页的概念列表按**日期倒序**排列（最新的在最上面）。

### 环境变量

本项目使用 `.env` 保存敏感配置（API Key、数据库密码等）。

1. 复制示例文件：`cp .env.example .env`
2. 在 `.env` 中填入真实值
3. `.env` 已被 `.gitignore` 忽略，**不会被上传到 GitHub**

### 目录结构

```
.
├── index.html        # 首页：概念列表（按日期倒序）+ 空状态 / 加载失败状态
├── concept.html      # 详情页唯一模板：按 ?id=<slug> 渲染固定 6 段
├── concepts.js       # 数据文件：全部概念记录，全站唯一的数据来源
├── README.md
├── PRD.md            # 产品需求说明（开发前的唯一需求基准）
├── research.md       # 竞品调研与差异化结论
├── TECH_DESIGN.md    # 技术方案（含 Day 23 接入数据库的规划）
├── AGENTS.md         # 协作规则
├── LICENSE
├── .gitignore        # 忽略规则：密钥、依赖、本地数据库等
└── .env.example      # 环境变量模板（仅含变量名，不含真实值）
```

**新增一条概念**：只改 `concepts.js` —— 在数组末尾追加 1 条记录，保存后刷新首页即可。
不需要打开、也不需要修改任何页面文件。
