# Day 25 自身的两条坑（本 Skill 的诞生原因）

| 坑 | 性质 | 处置 |
|---|---|---|
| `.gitignore` 写 `.workbuddy/` 后，加 `!` 例外**静默失效** | Git 不会进入被整目录排除的目录，例外规则不生效 | 改成「排除一级子项 `.workbuddy/*` → `!.workbuddy/skills/` → 对私有 skill 逐个精确排除」，并用 `git check-ignore -v` 实测验证 |
| 第 1 轮 5 个 FAIL 里**4 个是我自己的检查项写错** | 误报比漏报更危险：会让发布被无谓阻塞，或反过来让人忽略 FAIL | 引入铁律 6：**报 FAIL 必须区分「被测对象缺陷」与「检查项自身缺陷」**，汇总里分开计数 |
